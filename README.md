# AAAR 2026 Aerosol Box-Modeling Tutorial

Jupyter notebooks for the AAAR 2026 photochemical box-modeling tutorial, built on
[TOMAS-JAX](https://github.com/reflective-org/TOMAS-JAX): MCM gas-phase chemistry,
TUV-x photolysis and TOMAS aerosol microphysics with SOA partitioning.

Work in progress on branch `feat/aaar-tutorial`.
